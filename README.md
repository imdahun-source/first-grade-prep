# 나도 이제 1학년! 🎒🏫

만 5세 유치원생이 초등학교 1학년 생활을 미리 즐겁게 연습하는 학습용 미니게임 웹 애플리케이션입니다.

---

## 🌟 주요 특징

- **빌드 도구 불필요 (GitHub Pages 최적화)**: React나 번들러 없이 순수 `HTML`, `CSS`, `JavaScript`로 제작되어 별도 빌드 과정 없이 GitHub Pages에서 즉시 동작합니다.
- **5세 맞춤형 음성 & 큰 그림 중심 UI**: 글을 잘 읽지 못하는 아이들을 위해 모든 안내가 **한국어 음성(SpeechSynthesis, ko-KR, 약간 느린 속도)**과 대형 이모지/일러스트로 제공됩니다.
- **안드로이드 태블릿 크롬 가로 화면(Landscape) 최적화**: 터치 조작 최적화, 큼직한 버튼, 부드러운 오답 피드백(실패해도 무섭지 않은 효과).
- **무외부 API 키**: 브라우저 내장 API만 사용하여 네트워크 인증 문제 없이 언제든 동작합니다.

## 🎮 포함된 미니게임

### 1. 🎒 책가방 챙기기 (60초, 성공 1회당 20점)
- 매 라운드마다 오늘 챙겨야 할 물건 2~3개를 음성과 그림으로 안내합니다.
  - 예: *"오늘은 국어책, 필통, 실내화를 챙겨요."*
- 주황색 **국어책**(`국어 1-1`)과 파란색 **수학책**(`수학 1-1`)처럼 헷갈리기 쉬운 물건은 색상과 글자로 확실히 구분됩니다.
- 방해 물건(장난감 자동차, 곰인형, 게임기, 과자, 공)을 누르면 가방에 들어가지 않고 부드럽게 흔들리며 5점 감점(최소 0점)과 *"이건 오늘 필요 없어요"* 음성이 나옵니다.
- 목표 물건을 모두 가방에 넣으면 1회 성공(+20점)하며 바로 다음 라운드로 이어집니다.

### 2. 📖 교과서 펼치기 (60초, 성공 1회당 10점)
- 1쪽부터 100쪽까지의 교과서에서 목표 쪽수를 음성과 대형 숫자로 안내합니다.
  - 예: *"47쪽을 펴세요."*
- **책 옆모습(두께)**을 손가락으로 누르면 누른 위치 비례 ±3~5쪽 오차로 자연스럽게 펼쳐집니다.
- 펼쳐진 책에서 **◀ ▶ 큰 화살표**를 눌러 1장씩(2쪽씩) 넘깁니다. (왼쪽: 짝수 쪽 / 오른쪽: 홀수 쪽)
- 목표 쪽이 보이면 **"다 폈어요!"** 버튼을 누릅니다. 정답 시 +10점 획득 후 새 문제 출제, 오답 시 5점 감점과 친절한 방향 힌트(더 앞으로/더 뒤로)를 안내합니다.

### 3. 🚦 등굣길 건너기 & 🗺️ 학교 길 찾기

## 🚀 GitHub Pages 배포 방법

1. 새로운 깃허브 저장소(예: `first-grade-prep`)를 생성합니다.
2. 이 프로젝트의 파일들을 해당 저장소에 푸시합니다:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: 나도 이제 1학년! 웹앱"
   git branch -M main
   git remote add origin https://github.com/<사용자아이디>/<저장소이름>.git
   git push -u origin main
   ```
3. GitHub 저장소의 **Settings** → **Pages** 메뉴로 이동합니다.
4. **Build and deployment** 항목의 **Source**를 `Deploy from a branch`로 선택하고, Branch를 `main` / `/(root)`로 설정한 뒤 **Save**를 누릅니다.
5. 1~2분 후 생성되는 `https://<사용자아이디>.github.io/<저장소이름>/` 주소로 접속하면 바로 플레이할 수 있습니다.
